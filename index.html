      03 · Skills bank

      A shared language for what people can do.

      The bank separates portable capability from the function-specific context in which that capability is currently being used.

      SB
      Definition

      What is a Skills Bank?

      “The Skills Bank is a shared language for understanding the capabilities, knowledge and experience that exist across the organisation. It helps employees recognise skills they already use, understand how those capabilities translate across functions, and identify specialist knowledge they may want to build for future career moves.”

      Transferable capabilityA capability that can be applied readily across different functions.
      Adjacent / applied capabilityThe underlying capability transfers, but the way it is used differs between functions.
      Specialist knowledgeFunction-specific knowledge, systems, legislation, techniques or terminology that may need to be learned.

      04 · Previous examples

      Movement has already happened.

      These anonymised journeys show why cross-functional movement matters: a sideways move can be a bridge, an accelerator, or a way to return stronger.

      The core message

      You do not start from scratch when you move.

      You carry capability with you. The question is not “Do I already know this function?” but “What do I already have, how does it apply differently there, and what do I need to learn next?”
